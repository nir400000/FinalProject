## מבנה תיקיות
```
dataset/
├── images/                 <- שים כאן את כל התמונות שלך (jpg/png/...)
├── labels.csv                <- ייווצר אוטומטית ע"י pose_labeler.py
├── pose_classifier.joblib    <- ייווצר אוטומטית ע"י train_pose_classifier.py
├── pose_labeler.py            שלב 1: תיוג תמונות
```

## התקנה

```bash
cd dataset
```

## שלב 1: תיוג תמונות - `pose_labeler.py`
```bash
python pose_labeler.py
```

1. לכל תמונה, הכלי מריץ את מודל ה-Pose ומצייר עליה את השלד שזוהה.
2. אם זוהה **בדיוק אדם אחד** בתמונה - כפתורי התיוג (עומד/יושב/שוכב) פעילים.
3. אם זוהו **0 או יותר מ-1** אנשים - הכפתורים ננעלים באדום, ואפשר רק ללחוץ "דלג ומחק".
4. לחיצה על אחד מכפתורי התנוחה שומרת שורה חדשה ל-`labels.csv` ועוברת לתמונה הבאה.
5. אפשר לנווט אחורה עם "⬅ הקודם" (לתקן תיוג קודם).
6. **לחיצה על "דלג ומחק"** מציגה אישור, ולאחריו **מוחקת לצמיתות** את קובץ התמונה
   מתיקיית `images/` (מכיוון שהתמונה לא תויגה). כך בסוף התהליך נשארות בתיקייה
   רק תמונות שתויגו בפועל, וכל שורה ב-CSV תואמת לתמונה שעדיין קיימת בדיסק.
   ⚠ שים לב: הפעולה הזו בלתי הפיכה - מומלץ לשמור גיבוי לתמונות המקוריות לפני התחלת העבודה.

### קיצורי מקלדת בשלב התיוג
- `1` = עומד
- `2` = יושב
- `3` = שוכב
- חץ ימינה = דלג ומחק (עם אישור)
- חץ שמאלה = הקודם

### מבנה קובץ הפלט labels.csv
כל שורה מייצגת תמונה אחת שתויגה, וכוללת:
- `image_name` - שם קובץ התמונה
- `label` - התנוחה שנבחרה (`standing` / `sitting` / `lying`)
- `num_persons_detected` - מספר האנשים שזוהו (תמיד 1 בשורות ששמרתי)
- 17 נקודות מפתח בפורמט COCO, כל אחת עם 3 עמודות: `<name>_x`, `<name>_y`, `<name>_conf`
  (nose, eyes, ears, shoulders, elbows, wrists, hips, knees, ankles)

בהרצה חוזרת של הכלי, הוא ממשיך אוטומטית מהתמונה הראשונה שעדיין לא תויגה.

## שלב 2: אימון מודל הסיווג - `train_pose_classifier.py`
לאחר שתייגת מספיק תמונות (מומלץ לפחות ~20 מכל תנוחה, סה"כ ~60+):
```bash
python train_pose_classifier.py
```

מה קורה כאן:
- קורא את `labels.csv`, וממיר כל שורה לוקטור פיצ'רים בגודל 51: 34 קואורדינטות
  מנורמלות (17 נקודות × x,y, אחרי מרכוז סביב האגן ונרמול לפי אורך הפלג העליון -
  כך שהמודל לא תלוי בגודל/מרחק/מיקום האדם בתמונה) + 17 ערכי ביטחון.
- מאמן `RandomForestClassifier` (מ-scikit-learn) על הפיצ'רים, עם חלוקת train/test
  ו-cross validation, ומדפיס דוח דיוק מפורט (accuracy, precision/recall, מטריצת בלבול).
- שומר את המודל המאומן (יחד עם ה-scaler וה-label encoder) לקובץ יחיד:
  `pose_classifier.joblib`.

אפשר להריץ את הסקריפט הזה שוב בכל פעם שתייגת עוד תמונות, כדי לאמן מחדש מודל מדויק יותר.

## שלב 3: בדיקה חיה מהמצלמה - `webcam_pose_tester.py`
```bash
python webcam_pose_tester.py
```

פותח חלון (Tkinter) עם:
- תצוגת וידאו חיה מהמצלמה, עם השלד המזוהה מצויר עליה בזמן אמת.
- תווית גדולה וצבעונית שמציגה את התנוחה המסווגת (עומד/יושב/שוכב) יחד עם
  אחוז הביטחון של המודל.
- אם יש 0 או יותר מ-1 אנשים בפריים, מוצגת אזהרה והסיווג מושהה (עקבי עם
  הדרישה שהמודל יעבוד רק כשמזוהה אדם יחיד).
- מונה FPS בסיסי, כדי לראות את קצב העיבוד בזמן אמת.

לחיצה על "סגור" (או סגירת החלון) משחררת את המצלמה כראוי.

### דרישה מוקדמת
יש להריץ קודם את `pose_labeler.py` (לתיוג) ולאחר מכן את `train_pose_classifier.py`
(לאימון), כדי שיהיה קובץ `pose_classifier.joblib` בתיקייה.
